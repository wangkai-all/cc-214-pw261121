# 居民调查加权分析台（虚构数据演示）

一个**纯前端、零依赖、可离线运行**的调查数据分析页：从抽样框到区间估计的完整加权流程。
不连接任何真实调查平台，全部计算在浏览器本地完成，可直接用 `file://` 打开。

## 快速开始

```bash
# 方式一：直接用浏览器打开
open survey-analysis/index.html        # 或双击 index.html

# 方式二：本地静态服务（可选）
cd survey-analysis && python3 -m http.server 8000
```

打开后点击 **「载入虚构示例数据」**，然后按页面顶部 1–7 步顺序操作。

## 页面流程（七步，全部可操作、可导出）

| 步骤 | 内容 |
|---|---|
| 1 数据导入 | 四份数据（抽样框 / 抽中记录 / 回答结果 / 人口分层总量），支持 CSV/JSON 上传、模板下载、一键载入虚构示例 |
| 2 数据核查 | 连接校验、重复问卷去重（规则可选：保留最新/最早提交）、无效问卷与缺 π 记录清单 |
| 3 权重计算 | 基础权重 → 非响应调整（分组规则可选）→ 校准 → 可选截尾（页面设上限，展示处理影响） |
| 4 不可估计范围 | 总体覆盖率仪表 + 不可估计清单（缺 π 记录、整层无回答的层、缺人口总量的层） |
| 5 估计与区间 | 未加权 / 加权 / 截尾三列对照（比例与均值），重抽样 95% 区间，种子可复现 |
| 6 权重下钻 | 每条记录可展开查看完整权重计算链（π → 1/π → 非响应系数 → 校准系数 → 截尾） |
| 7 导出 | 权重明细 CSV、估计结果 CSV、不可估计清单 CSV、完整报告 JSON、方法说明 Markdown |

## 方法学

### 权重计算链（逐记录可下钻）

1. **基础权重** `d_i = 1/π_i`（π 为抽中记录中的入样概率）
2. **非响应调整** 按分组 g（层 或 区，页面可选）：`f_g = 组内抽中基础权重和 ÷ 组内回答基础权重和`，`w1_i = d_i × f_g`
3. **校准** 按层 s 对齐人口总量：`c_s = 层人口总量 ÷ 层内回答者 w1 权重和`，`w2_i = w1_i × c_s`
4. **截尾（可选）** `w3_i = min(w2_i, cap)`；页面显示被截尾记录数、权重和变化；截尾后不再重新校准，差额明示

### 不可估计规则（不硬算）

- **缺入样概率的记录**：不参与任何估计（包括未加权列，保证三列可比），列入清单
- **整层无人回答的层**：该层人口无法被代表，从加权目标总体中剔除；页面显示总体覆盖率（示例数据为 96.6%）
- **缺人口总量的层**：无法校准，保留非响应调整权重并标注「未校准」

### 点估计

比例与均值均为比率估计 `Σw·y / Σw`：未加权列 w=1，加权列 w=w2，截尾列 w=w3。
三列均仅基于可估计记录（有回答且 π 有效）。项目级缺失（如收入未填）按指标分别剔除并显示各自 n。

### 区间估计（重抽样，可复现）

**层内非参数 bootstrap**：每次在各可估计层内对回答者有放回抽取与原层相同数量的记录；
非响应调整系数沿用全样本值；**校准系数与截尾在每次重抽样内重新计算**；
取 B 次估计的 2.5% / 97.5% 百分位为 95% 区间。
随机数发生器为 mulberry32，种子固定（默认 `20261115`），**同一种子结果完全可复现**（有测试保证）。

### 已知局限

- 未包含多阶段/整群设计的设计效应；区间仅反映回答者层面的抽样与校准不确定性
- 非响应调整假设组内随机缺失（MAR）
- 整层无回答时任何加权方法都无法无偏代表该层，本工具选择明示而非硬算

## 虚构示例数据

由 `tools/generate-sample.js` 确定性生成（种子 20261115），覆盖要求的边界情形：

- **分层不均**：滨海区人口最少（1.5 万 / 8.8 万）但超比例抽样，各层基础权重 1.37–5.69
- **非响应集中**：滨海区 18-34 岁回答率约 23%，城西区 35-59 岁约 43%；滨海区 60 岁及以上**整层 30 人全部未回答**（触发不可估计路径）
- **重复问卷**：5 人重复提交（较早副本被剔除）
- **缺入样概率**：2 条已回答记录（HB0859、HB0755）→ 不可估计
- **无效问卷**：2 条回答不在抽中名单中；收入约 6% 项目级缺失

重新生成：`node tools/generate-sample.js`（会覆盖 `sample-data/*.csv` 与 `js/sample-data.js`）。

示例数据的典型结论：满意比例未加权 64.1% → 加权 61.5%（低满意群体回答率低，加权下修）→ 截尾（上限 662）62.3%；加权 95% 区间约 [54.3%, 69.4%]（B=500，种子 20261115）。

## 数据格式

四份 CSV（或同结构 JSON 数组），模板可在页面第 1 步下载：

- `frame.csv`：`person_id, district, age_group, sex, age`
- `selected.csv`：`person_id, pi, batch`（pi 为 0–1 的入样概率，可空 → 不可估计）
- `responses.csv`：`person_id, submitted_at, satisfied, community, exercise_hours, monthly_income`
- `population.csv`：`district, age_group, pop_total`
